一个为了方便用户上传文件到互联网档案馆（Internet Archives）而做的工具
代码均有Deepseek生成，可能含有很多bug
界面类似网盘风格，能满足基本的上传和下载需求，但仍未达到正常软件的标准
由于本代码只在华为畅享10 Plus（Android, Harmony3.0）下的Termux允许，不保证其他系统能正常运行

使用时必须安装Python（因为我还没打包，也不会做成apk）
使用方式：
1.下载本仓库所有代码，然后把代码放入termux内，允许python netdisk.py即可启动服务器
2.打开你的浏览器，输入http://127.0.0.1:5000/即可使用

禁止:
本工具初衷是为了方便失传媒体上传，禁止滥用（不要重复上传多个蓝光电影等）
